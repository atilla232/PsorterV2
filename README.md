# 🖼️ PSORTERV2 - Main Media Sorter (Foto & Video)

## 💻 SPESIFIKASI SISTEM

### 📌 Spesifikasi Minimum:
* **Sistem Operasi:** Windows 7 / 8 / 10 / 11 (64-bit)
* **Prosesor (CPU):** Intel Celeron / Core 2 Duo / AMD Athlon Dual-Core 1.8 GHz
* **RAM:** 2 GB (Sangat direkomendasikan menggunakan Mode Optimasi)
* **Penyimpanan:** 200 MB ruang kosong untuk aplikasi
* **Kartu Grafis (GPU):** Intel HD Graphics / GPU terintegrasi
* **Layar:** Resolusi minimal 1280 x 720

### 🚀 Spesifikasi Rekomendasi:
* **Sistem Operasi:** Windows 10 / 11 (64-bit)
* **Prosesor (CPU):** Intel Core i3/i5 (Gen 8+) / AMD Ryzen 3/5 Quad-Core 2.5 GHz+
* **RAM:** 4 GB – 8 GB (Untuk kelancaran Mode Normal)
* **Penyimpanan:** SSD (SATA / NVMe) untuk kecepatan *read/write* media
* **Kartu Grafis (GPU):** Integrated / Dedicated GPU dengan dukungan *hardware decoding* video 1080p
* **Layar:** Resolusi 1920 x 1080 (Full HD)
* **Tambahan:** VLC Media Player terinstall di sistem (opsional)

## ⌨️ PINTASAN KEYBOARD (SHORTCUTS)

| Tombol | Fungsi |
| :--- | :--- |
| **Panah Kiri / Kanan** | Navigasi ke foto/video sebelumnya atau berikutnya |
| **Spasi (Spacebar)** | Putar / Jeda video |
| **Enter** | Pindahkan / Salin file ke sub-folder pilihan |
| **Angka 1 s.d. 9** | Pindahan cepat (*Quick Move*) ke folder urutan 1–9 |
| **Ctrl + Z** | Batal (*Undo*) tindakan pemindahan/penyalinan terakhir |
| **R** | Rename file yang dipilih |
| **N** | Buat sub-folder baru |
| **Delete** | Hapus file secara permanen |
| **F5** | Refresh daftar file dan folder |
