## 💡 Cara Menjalankan Aplikasi

1. Klik tombol **Download** pada varian yang kamu inginkan. File `.zip` akan otomatis terunduh.
2. **Ekstrak** file `.zip` tersebut di laptop/PC kamu.
3. Jalankan file `.exe` di dalam folder hasil ekstrak. **Aplikasi bersifat portable (siap pakai tanpa perlu di-install).**

## 💻 Spesifikasi Komputer / Laptop

### 1️⃣ PSORTERV2 Lite (Single-Core Photo Sorter)
- **Spesifikasi Minimum:**
  * **Sistem Operasi:** Windows XP SP3 / 7 / 8 / 10 / 11 (32-bit atau 64-bit)
  * **Prosesor (CPU):** Single-Core 1.0 GHz (Intel Atom, Celeron lama, AMD Sempron)
  * **RAM:** 512 MB (Penggunaan memori aktif aplikasi hanya ~30 MB – 80 MB)
  * **Penyimpanan:** 50 MB ruang kosong
  * **Layar:** Resolusi minimal 1024 x 600
- **Spesifikasi Rekomendasi:**
  * **Sistem Operasi:** Windows 7 / 10 / 11 (64-bit)
  * **Prosesor (CPU):** Dual-Core 1.5 GHz atau lebih tinggi
  * **RAM:** 1 GB – 2 GB
  * **Penyimpanan:** SSD / HDD standar
  * **Layar:** Resolusi 1366 x 768 atau lebih tinggi
- **Keunggulan Pembaruan Kode (Lite Edition):**
  * **Bebas Beban Thread:** Berjalan penuh dalam satu antrean proses utama sehingga tidak memicu lonjakan suhu atau kemacetan pada prosesor 1 core.
  * **Efisiensi Memori:** Informasi dimensi dan ukuran foto hanya diproses saat foto ditampilkan di layar, membuat pembacaan folder berkapasitas besar tetap instan.

### 2️⃣ PSORTERV2 (Main - Foto & Video)
- **Spesifikasi Minimum:**
  * **OS:** Windows 7 / 8 / 10 / 11 (64-bit)
  * **CPU:** Dual-Core 1.8 GHz (Intel Celeron / Core 2 Duo / AMD Athlon)
  * **RAM:** 2 GB (Disarankan Mode Optimasi)
  * **Penyimpanan:** 200 MB ruang kosong
  * **GPU:** Intel HD Graphics / Terintegrasi
  * **Layar:** Minimal 1280 x 720
- **Spesifikasi Rekomendasi:**
  * **OS:** Windows 10 / 11 (64-bit)
  * **CPU:** Quad-Core 2.5 GHz+ (Intel Core i3/i5 Gen 8+ / AMD Ryzen 3/5)
  * **RAM:** 4 GB – 8 GB
  * **Penyimpanan:** SSD (SATA / NVMe)
  * **GPU:** Terintegrasi / Dedicated GPU (hardware decoding video 1080p)
  * **Layar:** 1920 x 1080 (Full HD)
  * **Lainnya:** Terinstall VLC Media Player (opsional)

### 3️⃣ PSORTERV2 Audio (Audio Deck Sorter)
- **Spesifikasi Minimum:**
  * **OS:** Windows 7 / 8 / 10 / 11 (32-bit / 64-bit)
  * **CPU:** Single-Core / Dual-Core 1.5 GHz
  * **RAM:** 1 GB – 2 GB
  * **Penyimpanan:** 150 MB ruang kosong
  * **Audio:** Sound Card bawaan / Jack Output
  * **Layar:** Minimal 1280 x 720
- **Spesifikasi Rekomendasi:**
  * **OS:** Windows 10 / 11 (64-bit)
  * **CPU:** Dual-Core / Quad-Core 2.0 GHz+
  * **RAM:** 4 GB
  * **Penyimpanan:** SSD
  * **Audio:** Sound Card / DAC (untuk pemantauan kualitas format Lossless FLAC/WAV)
  * **Layar:** 1920 x 1080
  * **Lainnya:** Terinstall VLC Media Player (dukungan codec lengkap)

---

### 4️⃣ PSORTERV2 Extensions (Universal Sorter)
- **Spesifikasi Minimum:**
  * **OS:** Windows 7 / 8 / 10 / 11 (64-bit)
  * **CPU:** Dual-Core 2.0 GHz (Set alokasi 2 Threads di Settings)
  * **RAM:** 2 GB (Set batas RAM Cache 256 MB / 512 MB)
  * **Penyimpanan:** 250 MB ruang kosong
  * **GPU:** Terintegrasi
  * **Layar:** Minimal 1366 x 768
- **Spesifikasi Rekomendasi:**
  * **OS:** Windows 10 / 11 (64-bit)
  * **CPU:** Quad-Core / Octa-Core 3.0 GHz+ (Set alokasi 4 – 8 Threads)
  * **RAM:** 8 GB+ (RAM Cache 1024 MB – 2048 MB untuk pemindaian puluhan ribu file)
  * **Penyimpanan:** NVMe SSD (Penting untuk efisiensi *batch move/copy*)
  * **GPU:** Terintegrasi / Dedicated GPU
  * **Layar:** 1920 x 1080 (Ukuran jendela aplikasi 1380x850)

## ⌨️ Shortcut Keyboard

| Tombol | Fungsi |
| :--- | :--- |
| **Panah Kiri / Kanan** | Navigasi file sebelum / sesudahnya |
| **Spasi (Spacebar)** | Play / Pause media (kecuali versi Lite) |
| **Enter** | Pindahkan / Salin file ke sub-folder pilihan |
| **Angka 1 s.d. 9** | Pindah cepat ke folder urutan 1–9 |
| **Ctrl + Z** | Batal (*Undo*) tindakan pemindahan terakhir |
| **R** | Ubah nama (*Rename*) file |
| **N** | Buat sub-folder baru |
| **Delete** | Hapus file |
| **F5** | Refresh daftar file & folder |
