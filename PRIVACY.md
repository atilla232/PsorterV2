## 🛡️ Kebijakan Pemrosesan Data & Keamanan
Aplikasi ini dirancang dengan prinsip **Zero-Data Collection**:
1. **Tidak Ada Telemetri:** Aplikasi tidak pernah mencatat, menyimpan, atau mengirimkan data aktivitas, nama file, maupun lokasi folder pengguna ke server mana pun.
2. **Koneksi Luar:** Satu-satunya lalu lintas jaringan yang terjadi adalah pemanggilan API GitHub publik (`api.github.com`) untuk memeriksa pembaruan versi. Pemanggilan ini tunduk pada Kebijakan Privasi GitHub (Microsoft).
